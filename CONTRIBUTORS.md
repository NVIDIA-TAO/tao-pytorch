## How to be listed

Land a pull request. Contributions of any size count — code, tests, documentation,
or examples. Add yourself to the table in the same PR, or ask a maintainer to add
you afterwards.

All contributions require a DCO sign-off (`git commit -s`); see
[CONTRIBUTING.md](CONTRIBUTING.md).

The authoritative record of contributions is the git history:

```bash
git shortlog -sne
```
